# Security Policy

## Supported versions

Only the latest published minor version receives security fixes.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report them privately through
[GitHub Security Advisories](https://github.com/ashiqu-ali/chat_image_editor/security/advisories/new).
Include steps to reproduce, the affected version and the impact you expect.

You can expect an acknowledgement within 7 days. Once a fix is released, the
advisory is published with credit to the reporter, unless you prefer to stay
anonymous.
